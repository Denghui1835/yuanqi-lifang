# 元气立方

> 以中医「治未病」为框架、以温暖陪伴为话术风格，同时照顾青少年身体与情绪的 AI 健康助手。
> 助手名叫 **小元**。

**当前状态：阶段零（机制验证）**。产品规划书 v2 已出，本机网页版演示可跑。

---

## 一句话

青少年的健康困扰，绝大多数落在医院和心理老师之间的中间地带——睡不好、老长痘、没精神、
容易烦、一考试就胃疼、跟爸妈说不上三句话就想摔门。这些状态够不上病，所以医院不接；
又都在身体上，所以心理老师也接不住。

而它们恰恰是中医「治未病」最擅长、也最适合介入的区间。

元气立方要做的，就是把这段被忽略的区间，做成一个 12 至 24 岁的年轻人愿意打开的入口。

---

## 核心洞察

### 一、身心同调：把情绪翻译成身体语言

产品最核心的机制，是把用户说不出口的情绪，翻译成一套他能接受、也看得懂的身体语言。
这不是修辞，是一套可执行的映射：

| 情绪 | 关联脏腑 | 常见证型 | 调理方向 |
|---|---|---|---|
| 怒 | 肝 | 肝气郁结、肝火上炎 | 疏肝理气、清肝泻火 |
| 喜（过度） | 心 | 心火亢盛 | 清心降火 |
| 思（思虑过度） | 脾 | 脾虚、心脾两虚 | 健脾益气 |
| 悲 | 肺 | 肺气虚 | 补肺益气 |
| 恐 | 肾 | 肾气不固 | 补肾固涩 |

当用户说「我很烦」，回应「别烦了」是无效的；而回应「心里憋着火，胸口是不是也堵得慌？
可以按按太冲穴」，同时完成了三件事——**被理解、被命名、被给到一个五分钟能做完的动作**。

### 二、话术是一等公民，不是提示词

多数 AI 产品把对话质量寄托在系统提示词里。本项目的做法不同：把话术做成结构化数据，
与证型一样入库、一样可维护、一样版本管理。因为话术就是本产品的核心差异点。

### 三、不做诊断

产品不做诊断、不给疾病名称、不替代就医。所有调理建议限定在传统养生范畴，
所有涉及自伤风险的情况一律转介监护人或专业热线。

**这条边界不是保守，是产品能长期活着的前提。**

## 与现有产品的差异

| 维度 | 通用健康助手（以蚂蚁阿福为代表） | 元气立方 |
|---|---|---|
| 文化根基 | 以西医诊疗体系为核心 | 以中医治未病三条原理为根 |
| 服务边界 | 覆盖咨询到诊疗的全链路 | 明确界定在治未病与家庭养生 |
| 目标用户 | 大众用户 | 12 至 24 岁青少年及其家庭 |
| 交互风格 | 效率优先 | 非暴力沟通，温暖陪伴 |
| 家庭维度 | 个人工具 | 家庭同心圆，全家健康同屏 |
| 文化融入 | 弱 | 每日经典、节气文化、家风家训 |

空白点在于「文化框架 + 陪伴话术」这一层。技术能力上没有代差，
真正的差异在定位——同样是接一个大模型，我们给它的不是医学知识库，
而是证型框架和一套**不允许评判用户**的话术规则。

```
└── .gitignore
```

## 跑起来

```bash
# 阶段零演示（双击 启动.bat 亦可）
python app.py          # 打开 http://127.0.0.1:8775

# 引擎自检（不联网也能验规则轨：危机检测 + 辨证 + 日签）
python xiaoyuan.py

# 重新生成规划书（需 python-docx）
python build_plan.py
```

> 规划书生成后目录是 Word 域，在 WPS 中打开需 `Ctrl+A` 再 `F9` 更新一次才有页码。

### 关于模型接口

演示默认直连 DeepSeek 官方接口，密钥读取顺序为环境变量 `DEEPSEEK_API_KEY`，
回退到 `~/.claude/settings.json` 里已配好的那条线路。

**两个本机踩过的坑，写在这里省得再踩：**

- 本机有代理（`HTTP_PROXY=127.0.0.1:7897`），但 `api.deepseek.com` **必须直连**，
  走代理必定 ProxyError。`xiaoyuan.py` 在导入时就把代理环境变量清掉了。
- `deepseek-flash` 是**推理模型**，`max_tokens` 给小了 `content` 会是空的
  （内容全落在 `reasoning_content` 里）。不要据此判断"模型不支持"，
  把预算调大即可——本项目取 3000。

## 开发路线图

| 阶段 | 目标 | 交付物 | 预估工时 |
|---|---|---|---|
| 阶段零：机制验证 | 验证中医话术是否比通用共情话术更有说服力 | 本机网页演示，含对话辨证、四维调理、危机响应三条链路 | 1 至 2 周 |
| 阶段一：最小可用版 | 跑通完整产品链路 | 网页版上线，七项功能中的前五项 | 4 至 6 周 |
| 阶段二：小程序化 | 完成目标形态 | 微信小程序上线，接入语音输入 | 4 至 6 周 |
| 阶段三：家庭与硬件 | 补齐家庭维度与可选硬件 | 家庭同心圆完整版、手环接入 | 8 至 12 周 |

「它怎么知道我不舒服」的惊讶，说明中医话术这个差异化并不成立，
此时应当果断调整，而不是继续投入去做完整应用。

### 阶段零要验证什么

整个项目的靶心是一个假设：**中医证型框架加非暴力沟通话术，相比通用 AI 助手的共情话术，
是否能显著提升青少年的持续使用意愿。**

如果试用者在对话中没有表现出「它怎么知道我不舒服」的惊讶，说明这个差异化不成立，
此时应当果断调整话术框架或重新审视定位，而不是继续投入去做完整应用。

对照组的做法很简单：把同一批问题分别喂给小元和通用助手，让被试盲评。

## 内容铁律

**引文必须核对原文，出处存疑的内容绝不入库。**

中医经典引文、方剂、穴位定位在入库前必须指回具体来源并标注篇名版本。
任何一条涉及身体调理的条目，都须复核是否标注了禁忌、是否存在替代就医的暗示。

宁可少，不可错。
